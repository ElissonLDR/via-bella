# Via Bella

Crie uma landing page com os seguintes regras a seguir:

- use a fonte Libre Baskerville para títulos, e open sans para textos, tamanho dos textos no máximo 16px;
- use as cores F2EBE2 gradiente para o fundo da página, e para conteiners com cor escura use 301E1A com gradiente claro em formato circular;
- a cor primaria deve ser a da marca C39B7F;
- use elementos arredondados, em cards, conteiners, botões;
- adicione hover nos botões de cor, e adicione um elemento de seta dentro de um circulo no canto direito dos botões, apontando para o canto superior direito, e no hover, ele aponta para a direita suavemente;
- use somente as imagens que enviar

ESTRUTURA DA LANDING PAGE

HERO

Criar um título extremamente forte.

Exemplo da linha de raciocínio:

"Leve uma marca desejada pelas consumidoras para sua loja."

Criar um subtítulo mostrando que a Via Bella oferece:

design atual

qualidade

modelos que acompanham tendências

excelente potencial de vendas para lojistas

Adicionar CTA.

BLOCO 2

POR QUE REVENDER VIA BELLA?

Criar benefícios para o lojista.

Exemplos:

✔ Produtos alinhados às tendências.

✔ Excelente apresentação.

✔ Marca consolidada.

✔ Mix variado.

✔ Modelos para diferentes estilos.

✔ Produtos que valorizam a vitrine.

✔ Renovação constante das coleções.

Não copie exatamente esses textos.

Crie argumentos melhores.

BLOCO 3

PROVA SOCIAL

Analise os materiais enviados.

Extraia provas sociais como:

presença digital

variedade do catálogo

qualidade das coleções

alcance da marca

quantidade de modelos

engajamento no Instagram

imagens reais

Caso existam depoimentos, utilize-os.

Caso não existam, NÃO INVENTE.

Utilize apenas provas reais.
